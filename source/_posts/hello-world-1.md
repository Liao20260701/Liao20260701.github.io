你好！这是我使用 **Hexo + Butterfly** 搭建的个人博客，部署在 GitHub Pages 上。

## 博客特性

- 内置浏览量统计（不蒜子）
- 暗黑模式
- 文章目录、搜索、标签
- 响应式设计，手机电脑都好看

## 代码示例

\\\javascript
function hello() {
  console.log("Hello, World!")
}
hello()
\\\

> 这篇文档的浏览量会显示在文章元信息区域，刷新页面即可看到计数变化。
